# Unity Gameplay Playground

A learning-focused Unity project for building reusable gameplay foundations before developing **Night Shift**.

The current movement sandbox contains a complete small gameplay loop: first-person movement, interaction, inventory, a locked door, objectives, NavMesh-driven enemy AI, capture, game over, and restart.

## Getting started

1. Open the project with Unity `6000.5.5f1`.
2. Open `Assets/Common/Scenes/MovementSandbox.unity`.
3. Enter Play mode.

Controls:

- `WASD`: move
- Mouse: look
- `Space`: jump
- `E`: interact
- `R`: restart after capture
